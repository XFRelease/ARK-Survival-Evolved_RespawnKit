第一章 · 软件总览

软件总览

重生赐装(RespawnKit)是方舟生存进化的服务端插件:玩家死亡重生或进入服务器(上线/传图/新角色)时,自动发放套装——护甲自动穿戴上身、物品发放进背包——解决官方"重生裸装"在直播画面里被平台判定违规的问题。全部行为通过一个 JSON 配置文件控制。

🛡️

重生/进服自动穿装

玩家重生或进服落地即自动穿戴整齐,直播画面不再停留在裸体状态。

👑

VIP 分组套装

套装绑定 Permissions 权限组,VIP1/2 与 VIP3/4 各发各的。

🧩

槽位自由配置

五件护甲加任意物品,每个槽位不配置就不给。

📈

品质数量可调

每件装备可单独设固定品质与数量,不同 VIP 不同档次。

🔄

热重载

RespawnKit.Reload 一条命令热重载配置,改套装不用重启。

🛠️

容错不罢工

蓝图写错只跳过该件并黄字提醒;配置缺节只停用本功能,插件照常加载。

第二章 · 环境要求

环境要求

项目要求
操作系统Windows(方舟 Windows 版服务端)
服务端框架ArkServerAPI(ArkApi)3.5 及以上(插件自述文件要求 MinApiVersion 3.5)
配套插件Permissions 插件(必需)——本插件通过它判定玩家 VIP 分组;未安装时本插件无法加载
配置存储JSON 配置文件一个(config.json),无数据库依赖
第三章 · 部署安装

部署安装

  1. 确认服务端已安装 ArkServerAPI

    服务器 ShooterGame\Binaries\Win64\ 下存在 ArkApi 目录 → 版本需 3.5 及以上 → 不满足先升级。

  2. 安装 Permissions 插件

    按 Permissions 插件自身的安装说明,把它的文件放到 ShooterGame\Binaries\Win64\ArkApi\Plugins\Permissions\ → 本插件依赖它,缺了无法加载。

  3. 复制本插件文件

    把 RespawnKit.dll、PluginInfo.json、config.json 三个文件复制到 ShooterGame\Binaries\Win64\ArkApi\Plugins\RespawnKit\(目录不存在就新建)→ 也可以用附带的一键安装.bat 自动部署(默认目标 F:\ARK\Servers 下的 1/2/3 号服,可在脚本顶部改 SERVER_BASE 和 SERVER_LIST)。

  4. 重启服务器

    重启后控制台出现 先锋.重生赐装(1.0) 启动横幅 → 继续下一步。

  5. 确认配置无报错

    控制台没有黄色警告(如 config.json 缺少 [重生赐装] 节) → 配置即正常;出现黄字按第六章常见问题处理。

  6. 在 Permissions 里建 VIP 分组

    服务器控制台执行 Permissions.AddGroup VIP1 → 提示 Successfully added group → 按需再建 VIP2、VIP3、VIP4 等分组。

  7. 把玩家加进分组

    服务器控制台执行 Permissions.Add 玩家SteamID VIP1 → 提示 Successfully added player → 该玩家重生时就会拿到对应套装。

  8. 对齐分组名并生效

    编辑 config.json 里各套装的"权限组",与 Permissions 里的分组名完全一致 → 执行 RespawnKit.Reload 热重载(或重启服务器)。

  9. 验证

    让一名已分组的玩家死亡并重生(或重新登录进服) → 约一秒后装备自动穿上、收到绿色提示 → 控制台出现发放日志即部署完成。

玩家 SteamID 可用 Permissions 的 Permissions.PlayerGroups 等命令查询,或在玩家进服时从服务器日志获取。
第四章 · 配置详解

配置文件说明

配置文件是服务器插件目录下的 config.json,完整路径:

<服务器根目录>\ShooterGame\Binaries\Win64\ArkApi\Plugins\RespawnKit\config.json
JSON 里逗号、引号、花括号一个都不能少。建议用带 JSON 校验的编辑器(如 VS Code)修改;改前先备份一份。配置损坏导致加载失败时,插件会在控制台输出错误信息。

第四章 · 配置详解

权限组与匹配规则

什么意思:"权限组"决定哪类玩家命中这套装备。组名必须与 Permissions 插件里的分组名完全一致(如 VIP1)。一套可以绑多个组——示例里 ["VIP3", "VIP4"] 表示 VIP3 和 VIP4 玩家共用这套。

兜底值:留空数组 = 匹配所有玩家。这是给非 VIP 玩家发基础套装的用法。

怎么加 / 怎么改:

"权限组": ["VIP1", "VIP2"]
"权限组": []

第一段只匹配 VIP1、VIP2 玩家;第二段留空,匹配所有玩家。

匹配规则(重要):每次触发(重生或进服)按套装列表从上到下找,第一个命中的套装生效,每次重生只发一套。

顺序就是优先级:如果把"权限组留空"的兜底套装放在列表最前面,所有玩家(包括 VIP)都会先命中它、拿不到高档套装。兜底套装必须放在列表最后。
第四章 · 配置详解

物品配置(蓝图 / 数量 / 固定品质)

什么意思:护甲槽位和物品数组里的每一条都是同一个"物品对象",七个键共用(在哪都用同一套):

键兜底值说明
蓝图必填物品蓝图路径;为空或缺失则该件直接跳过(不给)
数量1给予数量;须为正整数,写 0、负数或小数时按 1 处理;护甲、武器等不可堆叠物品数量大于 1 时自动逐件发放,弹药等可堆叠物品合并为一堆
固定品质0固定品质;0 = 白板,数值越高品质越高
固定伤害0武器伤害显示值(250 = 250%);0 = 不指定按固定品质
固定护甲0护甲值(500 = 500 护甲);0 = 不指定按固定品质
固定耐久0最大耐久值;0 = 不指定按固定品质
图纸falsetrue = 发放蓝图而非成品

怎么修改:不想发某件装备,删掉对应槽位或物品项即可——不配置就不给,完全按需。五个护甲槽位的名称固定为:头盔、胸甲、护腿、手套、靴子。

第四章 · 配置详解

行为开关(重生时给 / 进服时给 / 给装延迟秒)

什么意思:三个总开关控制赐装行为的触发时机。重生与进服是两个独立场景,各配各的开关。

配置键兜底值说明
重生时给true玩家死亡后重生时是否发放
进服时给true玩家进入服务器时是否发放——包括重新上线、跨服传图过来、新角色首次进服
给装延迟秒1触发后延迟几秒再给装,等角色完全就绪;0 或正整数,写负数按默认 1 处理(进服加载慢会自动重试)

怎么加:写在"重生赐装"节里:

"重生赐装": {
  "重生时给": true,
  "进服时给": false,
  "给装延迟秒": 2
}

怎么修改:"重生时给"/"进服时给"必须是 true/false,"给装延迟秒"必须是整数;类型不对时忽略该键、使用默认值(true / 1)。上面示例 = 只在死亡重生时发,进服不发。两个开关都关则功能整体停用。

第四章 · 配置详解

ConsoleEncoding(控制台编码)

什么意思:控制台输出的中文按什么编码显示,适配不同版本的方舟服务端控制台。

兜底值:auto(按控制台代码页自动探测)。

"ConsoleEncoding": "auto"

怎么修改:可选值 auto(自动)、gbk / ansi(强制 GBK)、utf8 / utf-8(强制 UTF-8)。写错值时回落 auto,并黄字提示 ConsoleEncoding 值非法: xxx , 已回落 auto;类型不是字符串同样回落 auto。

第五章 · 命令用法详解

命令总表与详解

本插件只有一条管理命令,在服务器控制台或 RCON 输入;没有玩家聊天命令。

命令权限作用改名配置键
RespawnKit.Reload控制台·RCON(管理员)热重载 config.json(含套装配置),不用重启服务器无(命令名固定)
符号约定:命令格式里的 [方括号] 表示可选参数,只是标注——实际输入时不要输入方括号。本命令无参数,示例是可直接照抄的真实输入。

RespawnKit.Reload

作用:重新读取服务器目录下的 config.json 并重建套装数据。改了套装、固定品质、分组名之后,执行它立即生效,不用重启服务器。

RespawnKit.Reload
参数必填缺省值说明
(无)——本命令无参数

示例:RespawnKit.Reload(在服务器控制台直接输入,或经 RCON 发送同名命令:重读配置并应用)。

反馈:成功时执行者收到绿色消息 Reloaded config(RCON 回包同文);失败(如 JSON 写坏)时收到红色消息 Failed to reload config(RCON 回包错误详情),此时继续沿用旧配置。服务器重启后配置自动重新加载,无需执行本命令。

第六章 · 常见问题

常见问题

玩家重生后没发装备?
按顺序查:① config.json 的"重生赐装"节和"套装列表"是否配置正确——配置有问题时控制台会出现黄字警告指明原因;② 玩家是否在某个"权限组"里(Permissions 控制台命令 Permissions.PlayerGroups 可查);③ 是否所有套装的权限组都非空、而玩家不在任何一组——需要兜底就加一个权限组留空的套装放列表最后;④ Permissions 插件是否已安装。
只发了一部分装备 / 物品没发出来?
控制台黄字 [重生赐装] 蓝图加载失败, 请检查路径: xxx = 路径无效;[重生赐装] 给予物品失败, 蓝图: xxx = 路径有效但该件入包失败。都只跳过该件、其余照发。修正蓝图后执行 RespawnKit.Reload;也可能是该槽位本来就没配置(不配置就不给)。
控制台提示"缺少 [重生赐装] 节"?
服务器插件目录下的 config.json 里没有"重生赐装"配置节(被删或损坏)。功能此时停用但插件正常加载。按第四章的完整示例补回该节,再执行 RespawnKit.Reload。
改了配置但不生效?
先确认改的是服务器目录下的 config.json(ShooterGame\Binaries\Win64\ArkApi\Plugins\RespawnKit\config.json),不是开发机编译输出目录里那份。改完执行 RespawnKit.Reload 或重启服务器。
怎么给没有 VIP 的玩家也发一套?
在套装列表最后加一个 "权限组": [] 的套装——留空匹配所有玩家。注意顺序:兜底套装放前面会被 VIP 玩家先命中,导致 VIP 拿不到高档套装。
怎么临时停用功能?
两种方式:① 删掉 config.json 的"重生赐装"节并 Reload——功能停用(黄字提示),插件继续运行;② 想连插件一起停:把 RespawnKit.dll 改名为 RespawnKit.dll.arkapi 后重启服务器(附带的一键安装.bat 也支持直接部署这种停用副本)。
控制台中文乱码?
把 ConsoleEncoding 改成与服务器控制台匹配的值:gbk 或 utf8(留 auto 一般也能自动探测)。改完 Reload 生效。
